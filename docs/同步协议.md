# 蓝笔 v1 个人同步协议

安卓和未来 iOS 使用同一套 Dart 模型、SQLite 表和事件格式。iOS 工程已生成，但尚未在 Mac 上编译或验证。

## 数据模型

SQLite 保存不可变事件。每次笔记修改、作答或题目修订生成随机 128 位事件编号。纯笔记与作答的备份继续使用 `schemaVersion: 1`；包含自建题目修订时使用 `schemaVersion: 2`。0.2 客户端与当前 Java 服务均接受两种格式。0.1 客户端不支持 v2；同一账号的设备使用自建题目前应统一升级。

事件字段：`id`、`lessonId`、`type`、`at`（UTC Unix 毫秒）、`payload`。

- note：payload.text。
- attempt：payload.variantId、rating（again/hard/good）、assisted、correct、reason。
- question：仅允许 user- 开头的自建题目编号。payload 包含有长度上限的题名、科目、章节、题干、公式、解答、四项关键点、来源、导入来源编号，以及 deleted 布尔值。完整字段由 questions.dart 校验。最新修订确定当前题面，删除修订隐藏题目，不把编辑操作计入学习次数。

复习状态由事件重建。首次无帮助且答对记为一次独立完成；依次采用 1、3、7、14、30 天间隔。答错或选择再次练习安排 10 分钟后；用过提示或勉强完成安排 1 天后。这是首版明确规则，不是 FSRS，也不是对迁移能力的保证。

## 同步接口

`POST /v1/sync`，JSON 请求正文与备份格式相同，使用 `Authorization: Bearer <个人同步口令>`。

Java 服务返回双方事件的并集。同一编号同一内容去重；同一编号不同内容拒绝整个请求。存盘原子替换完成后才确认成功。客户端将返回值事务合并至 SQLite。

第一版全量交换，最多 20,000 条记录、8MB 数据，适用于个人试用。它不是面向公开注册的多租户服务，不应共用口令给无关的人。

## 笔记与题目冲突

按客户端时间戳和事件编号排序，最后一条显示为当前笔记，旧版本保留。支持在笔记编辑页查看最近 10 个旧版本，并将其重新保存为新版本。

时间由设备提供，时钟偏差可能影响显示先后。首版保留历史避免静默丢失内容；未来公共服务应增加服务端顺序与明确的冲突解决机制。

自建题目使用同样的确定性排序；同设备连续修订保证时间戳递增。导入旧备份不会覆盖时间更晚的删除修订。来源于其他用户的题目包另存私人副本，同一个来源重复导入不覆盖本地编辑。这种包导入不等同于公共服务器发布。

## 传输与部署边界

客户端只接受 HTTPS，保留系统证书验证，不接受无效或自签名证书。同步口令只在当前页面内存中保留，不写入数据库或备份。

Java 伴随服务默认只监听本机 127.0.0.1:8787。它的 HTTP 接口供同机 HTTPS 反向代理访问。手机不能直接连接这个本机地址；必须先配置有效的 HTTPS 入口。当前项目没有自动部署公网服务、创建账号或申请域名。

测试只在本机隔离数据上验证 HTTP 服务逻辑。尚未验证安卓到已部署 HTTPS 服务的端到端通信，更未验证真实 iOS 设备。没有服务时，手动备份/恢复可以在安装了兼容客户端的设备间迁移记录。
