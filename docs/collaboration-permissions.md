# 笔记本协作权限方案

当前实现：创建者审批共同维护申请；共同维护者可以修改学习本简介和协作聊天。尚未实现完整的多人画布同步授权，不应把成员身份显示成拥有远程画布写权限。

下一阶段建议：
- 只读：浏览允许访问的版本，不能修改原本。
- 提交改进（默认申请权限）：在自己的工作副本修改，提交差异，由本主或管理员采纳。
- 直接编辑：仅由本主明确授予可信维护者，可同步修改授权范围内的章节/知识页。
- 管理员：由本主授予，可审阅改进及处理范围内的申请；不得转让所有权或授予超出自身范围的权限。

申请注明目标笔记本、章节范围、所需权限和理由；通知页提供同意、调整权限后同意、拒绝。服务器持久化审批人与时间，客户端收到确认后才展示已获权。UI不展示变化频繁的协作者人数。

写入必须由服务器逐次核验账号、笔记本及章节权限，不能依赖客户端隐藏按钮。撤销权限立即禁止新的远程写入，离线内容仍保留在用户本机，允许另存副本。

每次画布同步带基准版本号；版本不符返回冲突并保留双方修改，先对照再合并。整幅画布采用明确版本，第一阶段不做并发逐笔实时合并。私有内容只有通过明确的共享范围才可下载。

只读公开、私人设备备份、共同维护同步是不同操作，个人备份口令不能授予他人协作权限。用户点击“上传社区”仍需确认公开内容；离线保存不显示上传成功。
