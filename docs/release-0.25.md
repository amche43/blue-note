# Blue-note 0.25：更专注的笔记空间

- 导航调整为首页、探索、通知、我的四项；移除中间添加按钮、首页通知按钮、个人页我的学习本入口。
- 移除吉祥物插画和表情形象；默认头像改为简洁彩色头像，保留自定义照片审核。旧聊天中的表情标记以常规表情显示。
- 使用新启动图标；笔记本、章节和页面使用透明背景的线条图标。公开、待同步、只读、协作以实际已知状态呈现，照片页面显示图片标记，包含页面的章节显示文档标记。
- 首页及笔记本、章节、知识页列表：左滑显示上传和删除，操作需要确认；长按拖动排序。章节删除整组内容在一个事务中完成。
- 新建笔记本、章节后立即打开名称输入；取消或留空保留默认名称。新知识页自动聚焦标题。
- 移除知识本/便笺切换、默认排序按钮及单独的上传/删除按钮。已有未归档画布保留在笔记本列表，未删除用户内容。
- 画布菜单仅保留手写笔模式、横线开关、适合屏幕宽度。短暂停笔后自动保存，返回时等待保存成功，不弹出离开确认或保存成功提示。保存失败仍提示并保留页面。
- 画布靠近右/下边缘时自动增加空间，当前每个方向上限为 20000 画布单位。宽度跟随备份和分享保存，旧版固定宽度画布保持兼容。左边界阻尼跟手，松手后缓慢回弹。

## 仍需明确的边界

- 本机保存不等于公开上传。图标的上传状态来自服务器确认，橙点表示公开版本后又有本机修改；私有本机页面保持普通图标。
- 批量上传会跳过空白页和相同已发布版本；网络失败会报告已完成数量。现有后台不允许直接覆盖同题号的公开版本，需要先撤回旧发布，原讨论保留在旧版本中。
- 社区页根据后台 owner/member 状态显示公开、协作或只读图标。本机列表尚无远程画布授权与多人同步，不伪造参与编辑数量。子章节、代码及外链专用内容类型仍待后续数据模型完善。
- 内部保留崩溃恢复记录，不作为“草稿”展示；恢复仍受版本冲突保护，无法覆盖更新版本时会保留待恢复内容并提示。
- 使用自动化 Flutter 界面测试检查手机窄屏与宽屏布局，尚未在真实手写笔设备上验收触感。
