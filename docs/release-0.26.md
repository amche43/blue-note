# Blue-note 0.26：统一笔记本与学习图

- 首页是我的笔记本入口，不再显示查看全部；旧分类栏移除。界面统一使用笔记本、章节、页面，新页面默认名为新建页面1等。用户已有自定义标题不会被改写。
- 所有层级使用紧凑、透明背景列表，入口箭头取消，按下时显示白色反馈。
- 颜色按内容身份持久化，不再按列表位置分配。笔记本颜色可被章节继承，章节颜色可被页面继承；单独设置颜色后保留自己的颜色，改名和排序不改变已选颜色。
- 长按进入多选：左侧勾选、右侧调色及三条杠拖动柄。长按拖动柄排序，可以全选后批量改色，点击完成退出。普通模式仍可左滑上传或删除并二次确认。
- 页面内移除主动保存按钮；仍静默自动保存，保存失败保留提示。公开与待同步状态显示在列表入口图标上，私有本机页面不假装已经同步到社区。
- 学习贡献图改为学习图，日期明细同时显示时长和贡献。色阶同时受贡献次数和学习时长影响；不在页面上堆叠色阶说明。
- 学习时长从本版本开始记录画布前台使用时间。操作后超过60秒无交互暂停计时，切后台暂停，跨午夜按日期分别记账。阅读时持续不触屏的时间会较保守地计入；这不是全天屏幕使用时间，也不会编造过去的学习时长。
- 本机持续进步成就：每周有有效贡献，或累计学习满30分钟，均计入活跃周。公开贡献类成就规则保留，当前本机时长未向社区上传认证。
- 不再出现欢迎引导页，启动直接进入首页。Android自适应启动图标增加安全边距，避免圆形蒙版裁切。
