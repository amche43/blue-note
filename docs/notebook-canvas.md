# 蓝笔 0.22：笔记本与手写画布

现在从学习本进入的是章节列表；进入章节后，才看到题目标题，点击打开画布。可新建空章节、搜索章节里的题目；题目左滑仍可删除并二次确认。

## 从哪里开始

- 已有学习本：我的学习本 → 某一本 → 新建/打开章节 → 新题目。
- 从添加页开始：新建手写画布。右上角「⋮ → 学习本、章节与科目」可以归档，也可先不归档。
- 标题自己填写；留空后使用「第N题」或「未命名题目」。已取消自动/规则标题建议。

## 画布工具

手机工具栏可以左右滑动，撤销、重做固定在右侧；长按图标可以看名称。

| 工具 | 使用方法 |
| --- | --- |
| 移动/缩放 | 切到手掌工具，拖动移动，双指或触控板缩放。更多菜单可适合屏幕宽度。 |
| 普通笔 | 在画布上书写；可选择颜色、粗细。 |
| 荧光笔 | 半透明高亮；独立保留上次选择的颜色与粗细。 |
| 思路标记 | 在荧光笔选项中勾选，画完后写说明。蓝色圆点与普通高亮区分；用选择工具点击后才显示说明，可修改。 |
| 整笔橡皮擦 | 接触笔迹或线条图形即移除整个动作；擦除范围可调，撤销恢复整笔及附着说明。照片、文字与表格通过选择工具删除。 |
| 文字 | 点击画布选择位置，输入文字；可选颜色与字号。之后选择文字，再点编辑。 |
| 选择 | 点击选择对象，或拖出矩形框；可移动、删除、编辑文字/表格/思路。 |
| 插入空行 | 点击位置，下面完整的对象向下移动三行；跨越该位置的单个对象不拆开。可撤销。 |
| 图形 | 选择矩形、椭圆或直线后拖动绘制。 |
| 表格 | 选择行列数后拖出表格，选中后通过「编辑」逐格填写。 |
| 照片/识字 | 可直接插入题目、答案照片；或发送至已配置的本机识字后台，人工核对后插入文字。 |

画布右上角勾号正式保存。未保存修改有本机草稿，返回时可选择保存或保留草稿；添加页草稿箱可以恢复。自动草稿不等于公开提交。

## 从某一步单独提问

用选择工具框住区域 → 复制为新题 → 选择目标学习本、填写章节与标题。

这一版复制的是**框内可见内容的裁剪照片**，放在新题画布上，可以继续写字、标注和插入文字。框外像素、隐藏思路说明不会带过去；原题保持不变。复制后的旧笔迹已成为照片，不能逐笔擦除，新增笔迹可以逐笔编辑。

## 保存、社区与旧数据

- 学习本页与画布更多菜单提供上传至社区入口。发布前可预览画布，必须确认公开；思路标记属于正式画布内容，会随发布一同公开。
- 草稿、私人学习记录与识别原始记录不随社区发布。
- 社区仍是本机开发测试。先更新并重启 `blue-note/server` 下的后台；旧后台没有画布能力时，App 会拒绝发布，防止只上传标题。
- 正式画布保存为笔迹/文字/图形对象，不是整页截图；完整备份和新版同步保留这些数据。选区复制例外，使用裁剪照片。
- 旧题目首次打开时把文字、照片放到画布，正式保存后以画布为主；原始版本仍留在保存历史中。当前画布工具提供本次编辑的撤销/重做；画布版本的可视化逐项对照恢复尚未接入新编辑页。
- 带有自己思路说明的画布可计入有效学习内容；仅批量插入照片或随手画几笔不因此获得成就。

## 手机、平板和电脑

窄屏使用横向工具栏，宽屏增加同章题目侧栏。鼠标可绘制，Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Y 重做。更多菜单提供「仅手写笔绘制」，用于忽略手指绘制；若设备把触控笔识别为手指，可关闭该选项。

本次交付仍是 Android APK，兼容布局已用手机与宽屏 Flutter 测试检查；没有发布 Windows 或 iOS 安装包。手写笔压感、不同硬件上的防误触表现尚未完成真机验证；没有新增手写公式识别或付费 AI。

第一版每页最多3000个动作、20000画布单位高、8MB画布数据；可向下扩展页面，较长笔记建议拆为多个题目。旧个人同步服务整份日志仍有8MB上限，图片较多时使用完整备份。
