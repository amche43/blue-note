# 蓝笔内容整理规范

每个学习单元保存为 assets/lessons.json 中的一项。首批内容为 7 个单元、16 道变式。

## 从 PDF 或对话整理

1. 确认原题完整条件、问题、图表及页码。看不清的公式、图中边权、上下限应标记待确认，不根据答案反猜题目。
2. 记录用户实际卡点，区分未学、遗忘、没想到、适用条件误解、计算或实现错误。
3. 独立重新推导解答。旧对话中的回答只作线索，不直接当成经过验证的题解。
4. 抽取触发线索、关键动作、适用条件、误用边界，并链接对应的知识卡片。
5. 至少编写一个迁移或边界辨析题。每道选择题要有唯一正确答案、明确条件和解释。
6. 保留来源描述。根据疑问重新编写的例题要注明，不能写成原题复刻。

## 内容字段

- id：稳定标识；发布后不要因为改标题而修改，以免断开笔记关联。
- subject、chapter、title、prompt、formula：科目、章节、方法名称、完整题干、可选 LaTeX 公式。
- hints：从观察线索到关键步骤递进，避免第一条直接给答案。
- steps：逐步解答，含 text 与可选 formula。
- blue：trigger、action、conditions、pitfall。
- concepts：知识卡，含 id、title、body、可选 formula。
- variants：变式题，含稳定 id、kind、prompt、options、answer（从 0 开始的下标）、explanation、可选 formula。
- source：内容来源和是否改编。

步骤中的 `[[concept-id|显示名称]]` 会显示为可点击的知识点下划线。

## 发布前检查

运行 Flutter 测试，核对全部公式可渲染、下划线引用存在、选择题答案与解释一致。再人工检查数学条件与计算机专业术语。

首批旧对话来源为《高数2》《数据结构》《计网》的部分近期内容，尚未扫描或整理所有历史对话。原图不清楚或未读取完整的题目不作为原题导入。
