# 蓝笔 · 安卓试用版 0.19

面向大学生的开源学习协作平台。创建错题本、知识本，记录自己的理解，与学习伙伴共同改进。Open Your Learning.

## 当前版本

现有录入与修改历史支持逐字段对照和选择恢复，默认不勾选。恢复新增一次保存，不删旧版本，保留未选字段、学习本归属、题号、照片识别记录和复习进度。保存时核对当前基准，冲突时拒绝覆盖；只允许同条目非删除历史。编辑页没有未保存修改时，返回后显示恢复结果；已有草稿则保留并继续受冲突保护。

创建页新增「我的草稿箱」，集中查看保存时间、所属学习本和识别记录标记。支持类型筛选、标题/正文/学习本搜索、返回对应编辑入口和确认删除；删除只影响草稿，不改正式题目。异常草稿保留并提示，不自动清理。

分步录入和题目编辑支持本机草稿自动暂存、退出保留和同入口恢复。正式保存与草稿清理同一事务；旧草稿遇到已改变的原题会停止覆盖，可另存为新条目。草稿暂不在完整备份/跨设备同步内，迁移前应正式保存。

原作对照支持选择性采纳：默认不勾选，逐项查看前后内容，确认后只替换所选字段，保留私人理解。采纳与历史原子保存，历史支持离线查看和安全撤销；采纳字段有后续修改时拒绝自动撤销。完整备份携带历史与撤销状态。暂不支持原作新增条目一键导入或自动合并。

派生学习本提供「原作更新与对照」：查看相对派生时的新增、修改、撤回，逐字段对照原作旧版、当前公开版和私人版本，标记双方修改。检查本身只读，不上传私人内容或覆盖记录，可手动打开自己的编辑器或选择采纳。当前按进入页面/刷新检查，无推送或自动合并。

我的页面提供12类四级成就与开放学习履历；点击公开学习本或条目的作者可查看公开成果。门槛按有效内容、复习掌握、公开时长、采纳改进、实际维护、单本收藏和独立帮助人数计算。私有学习与后台公开数据分别核实，不自动上传私人复习记录。

学习本支持提交改进、作者接受/拒绝、通知查看处理结果；基于他人公开本创建私有版本，原样复制不计派生成就，修改后才计入，保留来源并随完整备份恢复。当前仅支持单次200条/16MB以内派生，不自动同步原作更新。

头像目前保留8个角色，可在编辑资料选择自定义照片并提交本机管理员审核。创建页、透明吉祥物、完整学习备份已接入。徽章为透明背景的简化绘制图标，特殊成就除一年维护外仍待可靠数据支持；当前进度非永久获奖账本。

更新 APK 后需重启本机社区后台。仍为本机测试产品，没有公网部署、系统消息推送或应用商店发布。以下为历史版本说明，其中当时未实现的能力以上述当前版本为准。

## 产品方向与0.6

面向大学生的开源学习协作平台。以学习本为核心，开源你的学习过程。正式方向与后续协作依赖见 PRODUCT_DIRECTION.md。

本阶段：首页学习工作台、知识点本、先回想再展开的知识卡片、公开本子搜索与点赞收藏排序、三步快捷录入、原图/OCR/用户确认结果分离保存、思考过程和修改历史、近365天真实记录贡献图，以及用户提供的品牌图标、头像和表情。使用步骤见工程外 outputs/蓝笔0.6更新说明.md。

提交改进合并、整本派生、关注更新尚未实现；0.8共同维护目前仅含简介与协作聊天；当前本子探索由公开条目聚合，发布仍逐条确认。照片仅存当前设备，不进入文本备份。多模态模型和公式OCR尚未配置，AI结构化结果保持为空，不伪造完成状态。

## 0.5 错题本与照片录入

可建立私人错题本，题目使用固定编号，删除后不重排。主动发布的题目在社区按作者和错题本归类，可复制引用定位到某次发布的具体题目。未发布内容保持私有。

安卓支持相册和拍照取图，经同意发送到本机后台，用 RapidOCR 在 CPU 上读取印刷文字。结果必须编辑核对后才能填入题干；暂不支持可靠的公式、图形理解或自动推导关键点。完整使用步骤见工程外 `outputs/蓝笔0.5更新说明.md`。

代码使用 MIT 许可，贡献说明见 CONTRIBUTING.md，题目和照片的内容范围见 CONTENT_POLICY.md。没有上传 GitHub 或开放公网服务。

## 0.4 复习与回想

新增复习中心、科目与卡点筛选、收藏、最多5单元混合练习，以及可追加笔记的主动回想页。回想不自动计分，24小时内重复独立答对不推进复习级别。收藏仅保存在本机。使用说明见工程外 `outputs/蓝笔0.4更新说明.md`。

## 0.3 本机社区

新增独立 Python + SQLite + HTTPS 本机社区后台，与原 Java 个人同步服务分离。支持确认发布、下载、评论、点赞、撤回与纠错反馈回执。运行和管理方式见工程外 `outputs/本机社区试用说明.md`。没有购买或部署互联网服务器。

## 已实现

- 自主添加、编辑、删除题目；可先存题干，再补公式、解析、关键点和来源。
- 按关键词查找参考例题，用户核对后引用关键点；不代表自动推导出解法。
- 经用户明确同意后复制题目包；导入时预览并保存私人副本，不覆盖已有编辑。
- v2 私人备份与同步支持自建题目，同时兼容 v1 笔记和作答数据。
- 今日推荐、科目筛选、章节/方法/笔记搜索。
- 循序渐进与直接挑战；分层提示、逐步解答、可点击的知识点说明。
- 7 个学习单元、16 道变式，覆盖高数、数据结构、计算机网络。
- 自己编辑蓝笔总结；保存笔记历史，支持回看旧版本。
- 记录第一次作答结果、提示使用情况和卡点原因；安排复习。
- SQLite 本地保存，关闭后重新打开仍保留记录。
- 复制文本备份与事务合并恢复，重复导入不重复计数。
- HTTPS 同步客户端与 Java 个人同步伴随服务。
- 共用 Dart 数据模型和 iOS 工程骨架，为后续 iOS 版保留同一数据格式。

## 开始使用

安卓安装包已生成并通过签名、应用名称和内容校验：outputs/blue-note-0.4.0.apk。支持 Android 7.0 及以上系统，包含 ARM 32 位、ARM 64 位和 x86_64 架构。用户已在模拟器上运行 0.2；0.4 尚待模拟器交互验证，详见 docs/验证记录.md。

安装现成 APK 无需再编译。后续修改源码时，在原开发电脑上可双击工程外 outputs/build-android.cmd，使用已下载的工具重新生成安装包。构建成功后会校验并按实际版本输出 APK。构建日志保存在同目录 android-build-local.log。这个入口依赖当前工程旁的 work 工具链目录，不是移到其他电脑即可使用的便携安装器。

将 APK 传到安卓手机并打开安装。进入应用后，从“今日”开始，无需注册。先完成一个例题，再试做变式。在“我的”里可导出备份；请将备份文本保存到自己的文件中。

没有安卓手机时，可用 Android Studio 的安卓模拟器安装，参见工程外 outputs/电脑试用教程.md。自主录题位于“学习 → 添加我的题目”，填写名称、科目和题干即可先保存，右上角也有保存按钮。

这是本机试用版本，尚未发布到应用商店。核心学习可离线运行，本机社区和OCR需要电脑后台。自动 PDF 解析、互联网公开服务、公共账号注册和托管云端服务尚未实现。

旧对话只读取并整理了部分内容，并非所有历史题目。已重新核对表述、补足条件，并在单元底部标注来源。后续可继续提供 PDF，通过当前对话整理成新的内容包。

## 数据互通

安卓与未来 iOS 使用相同的记录格式和服务接口。当前已经验证两份客户端数据的合并与去重，但 iOS 尚未在 Mac 或苹果设备上编译测试。

第一种方式是手动备份恢复，不依赖服务器。第二种是自行运行 Java 同步服务，并配置有效的 HTTPS 入口。当前没有开箱即用的云端地址，不能把“已实现同步接口”理解为“云同步已部署”。详情见 docs/同步协议.md。

含自建题目的备份使用 v2，不能导入 0.1 客户端。使用个人同步的设备和 Java 服务需一同升级。当前公开下载、照片文字识别、评论和点赞仅在本机测试社区使用。旧规划文档代表历史计划，以本文及 PRODUCT_DIRECTION.md 为准。

## 开发

使用 Flutter 3.47.2、Dart 3.13.2。Android 工程使用 SDK 36。依赖已锁定在 pubspec.lock；iOS 编译需要 macOS/Xcode。

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Java 服务只使用 JDK 17 标准库，无 Maven 或额外依赖。默认只监听本机，数据保存在 server/data/journal.json。

```powershell
# 自行设置并妥善保存一个足够长的随机口令；不要提交到版本库。
$env:BLUE_NOTE_TOKEN = '<至少32字符的个人随机口令>'
cd server
./start.ps1
```

手机端只接受 HTTPS 并校验证书。Java 本机接口需放在同机 HTTPS 反向代理后使用；服务端测试使用隔离的本机临时数据。

```powershell
python server/test_sync.py
```

## 工程结构

- lib/main.dart：应用页面和学习流程。
- lib/domain.dart：跨平台事件格式、校验、复习状态重建。
- lib/store.dart：SQLite 保存、备份、HTTPS 同步。
- assets/lessons.json：可扩充的内容包。
- android / ios：平台工程。
- server：Java 个人同步服务与测试。
- docs：内容整理规则与同步协议。
- test：数据持久化、复习规则、学习流程、公式和窄屏排版测试。

首版 Android release 构建仍使用开发签名，仅用于个人试用。正式发布前应配置长期发布密钥。更新安装须保持包名和签名一致；卸载会清除本机记录，操作前请备份。
